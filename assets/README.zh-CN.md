# 场景资产

[English](README.md) | **简体中文**

按[安装说明](../README.zh-CN.md#环境安装)配置好模拟器后，在仓库根目录运行以下命令，将 `L2-01` 换成要评测的关卡编号：

```bash
python setup_assets.py --level L2-01
```

安装器从官方来源下载资产，保存到 `assets/datasets/`。此步骤不需要模型 API key。

| 关卡 | 所需资产 |
|---|---|
| L2、H2 | 机器人资源。房间布局由本仓库代码生成。 |
| L1、H1 | 机器人资源，以及 BEHAVIOR 房屋和物体数据集。按提示查阅数据提供方的许可条款。 |

已安装的资产供多个关卡共用。请勿提交下载的数据集、授权文件或 API key。
