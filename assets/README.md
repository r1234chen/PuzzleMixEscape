# Scene assets

**English** | [简体中文](README.zh-CN.md)

After [installing the simulator](../README.md#setup), run this command from the repository root, replacing `L2-01` with the level you want to evaluate:

```bash
python setup_assets.py --level L2-01
```

The installer uses official sources and stores the downloads in `assets/datasets/`. It does not need a model API key.

| Levels | Assets required |
|---|---|
| L2, H2 | Robot assets. Room layouts are generated by the code in this repository. |
| L1, H1 | Robot assets plus the BEHAVIOR house and object dataset. Review the upstream data terms when prompted. |

Installed assets are shared across levels. Do not commit downloaded datasets, authorization files, or API keys.
